# Cobblemon MBTI

Client-side Fabric mod that shows each Pokémon's **MBTI type** at the right end of the **Nature** box in Cobblemon's
Summary. Yes, only showing; nothing too fancy about it.

For Minecraft version 1.21.1 with Fabric.
Supports Cobblemon 1.7.3+ (not tested with older versions)

# Feedback
If you have any questions, issues, or requests about the mod, you can leave them here!

# Disclaimer:
Most Pokémon's MBTIs come from people's votes on Personality Database website, and some come from my research with a bit of AI help.
